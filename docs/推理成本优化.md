### 【整合版】

**领域自适应投机采样推理系统 | 独立开发 · 开源项目**

**技术栈：** Python, PyTorch, vLLM V1（官方扩展点 `custom_class` + 引擎内薄 patch）, PagedAttention, Speculative Decoding, LoRA, FastText

**项目背景：** 在企业知识库 RAG 场景中，长上下文检索增强请求的解码成本占主导；同时单一固定草稿模型在中文问答 / 代码生成 / RAG 三类请求上的投机接受率差异显著，导致加速效果不稳定。本项目基于 vLLM V1 构建领域自适应投机采样框架，通过请求级草稿路由与复制型内容的零成本草稿源，在不改变输出分布的前提下提升解码吞吐。

**核心工作：**

- **领域自适应路由与草稿池设计：** 构建同族同词表草稿池（Qwen3-0.6B / 1.7B / 4B），设计「关键词 + FastText」两级请求级路由器（开销 <5ms），结合会话级粘性绑定与滑动窗口接受率监测，实现草稿模型的动态匹配与自动降级兜底，解决固定草稿跨领域加速不稳定问题。
- **vLLM 引擎内多草稿调度：** 基于官方扩展点 `custom_class` 实现自定义 proposer 与多草稿注册表，突破单引擎仅支持单个草稿模型的限制；实现草稿权重换入换出（或 LoRA 草稿头切换）与每请求草稿绑定，并处理其与 CUDA graph 捕获、prefix cache 生命周期的冲突。
- **RAG 场景零成本草稿：** 针对引用型输出大量复用输入片段的特性，采用 prompt-lookup (n-gram) 作为零成本草稿源，并在合成长上下文（4-8K）档位评估复制命中率与接受率增益。
- **严谨评测与无损性验证：** 采用 vLLM 原生指标体系统一记录接受率、逐位置接受分布、TPOT、吞吐与显存；在采样口径下逐 token 比对输出分布一致性；明确界定原型边界（BS ≤ 8 最优区间、高并发衰减规律）。

**目标指标（待测，以 P5 实测报告为准）：**

- **推理性能：** 相比全局固定草稿基线，中小 Batch 下平均 TPOT 降低约 57%，单请求吞吐提升约 2.3×；领域内平均接受数由 2.1 提升至约 3.6。
- **业务收益：** 三场景联合测试集上接受率提升约 31%，同质量下单位 Token 算力成本下降约 45%；RAG 长上下文档位 prompt-lookup 复制命中率约 82%。
- **工程质量：** 拒绝采样无损验证；代码、评测脚本与复现文档开源（GitHub 待补）。
